[MEDIUM] 5. CameraFollow.cs — Deadzone 분기 중복
============================================================

라인 66~69
    if (target.position.x < deadMin.x) targetPos.x = target.position.x;
    if (target.position.x > deadMax.x) targetPos.x = target.position.x;
    if (target.position.y < deadMin.y) targetPos.y = target.position.y;
    if (target.position.y > deadMax.y) targetPos.y = target.position.y;

  - 양쪽 모두 target.position.x/y 그대로 할당하므로
    Deadzone 경계와 동일한 위치로 카메라를 끌어당기는 부드러운 효과를 살리지 못함.
  - 의도가 "Deadzone 밖일 때 그 경계까지만 따라가기" 였다면 다음과 같이 수정:
        if (target.position.x < deadMin.x) targetPos.x = target.position.x - (deadMin.x - cameraPos.x) ...
    혹은 명확하게:
        if (target.position.x < deadMin.x)
            targetPos.x = cameraPos.x + (target.position.x - deadMin.x);

[LOW] 6. 더블 점프 카운터 의미 모호
============================================================

Assets/Scripts/Player/PlayerController.cs:219~241
    if (grounded)             jumpCount = 1;
    else if (jumpCount <= extraJumps && extraJumps > 0)
                              jumpCount++;

  - extraJumps = 1 일 때
      지상 점프 후 jumpCount=1,
      공중에서 1 <= 1 → true → 더블 점프 발동 후 jumpCount=2,
      다시 검사 2 <= 1 → false → 3단 점프 차단.
  - 결과적으로 의도("추가 점프 N회") 와 동작은 일치하나
    카운터의 시작값(1)·비교 연산자(≤)의 조합이 직관적이지 않음.
  - 권장: jumpCount=0 부터 시작, 비교는 `jumpCount < extraJumps`.
